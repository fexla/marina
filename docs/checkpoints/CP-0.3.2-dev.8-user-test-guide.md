## 请人工复验 A：文件预览位置（本版主项）

1. 在终端 A 的右侧“已打开”面板打开一份较长的 Markdown。
2. 滚到中间一个容易辨认的标题，确保既不在顶部也不在底部。
3. 依次执行并返回原文件：
   - 切到另一个已打开文件再切回；
   - 切到“文件”面板再切回“已打开”；
   - 切到终端 B，再切回终端 A。
4. **预期**：每次返回都仍停在原来的标题附近，不跳到顶部或底部；不同文件互不串位置。

## 请人工复验 B：Diff 位置与布局

1. 打开一份同时需要横向、纵向滚动的长 Diff。
2. 向下滚一段，再向右滚到代码中部。
3. 切到其他文件或终端，再返回该 Diff。
4. **预期**：
   - 横向和纵向位置都恢复；
   - 左侧数字/符号栏仍固定且与代码行对齐；
   - 分隔线是低对比主题色，不再出现亮粉色；
   - 代码不会穿进数字栏。
