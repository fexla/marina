# Marina v0.3.3 用户测试指南

> **用途**:v0.3.3 发版前的人工实测清单,一次性把所有 feature 验证完。
> 自动化测试(typecheck/lint/vitest)已全绿(1187 通过),这里只验「自动化测不到、
> 需要人眼看 / 鼠标点」的 UI 与交互。
>
> **反馈格式**:`<编号> 通过 / 失败:现象`。失败时附 `~/AppData/Roaming/Marina/logs/main.log` 最后 50 行。
>
> 配套夹具:`docs/test-fixtures/v0.3.3-smoke-test.md`(Feature A/B/表格共用)。

---

## §0 准备(预计 3 分钟)

1. **依赖**:`node --version`(需 20+),首次 `npm install`(2-3 分钟)。
2. **启动 dev**:`npm run dev`。等 ~10 秒出现 Marina 窗口。
3. **CLI 调用方式**:`marina` CLI **不在 PATH 上**,必须用路径调用。在 Marina 终端里(MARINA_SERVICE 已注入)这样调:
   ```powershell
   # PowerShell(推荐先设个别名,后面测试省事)
   $m = "$PWD\src\skills\show-in-marina\marina.cmd"
   & $m ping          # 应打印 "marina: online"
   ```
   后文 `$m` 都指这个路径。先 `& $m ping` 确认 online 再继续。
4. **建一个本地终端 session**:开个 PowerShell 终端(不是 SSH),后面大多数测试基于它。
5. **打开夹具**(测 Feature A/B/表格用):
   ```powershell
   & $m show "$PWD\docs\test-fixtures\v0.3.3-smoke-test.md"
   ```
   预期:右 dock 自动切到「已打开」,显示这个 md。

## §1 Feature F · 终端路径 → 可点链接(新,2 分钟)

**前置**:已在跑某个会输出文件路径的命令的本地终端(非 SSH)。

### F-1 自动链接(带斜杠路径变蓝可点)
1. 在终端跑:`npx tsc --noEmit -p tsconfig.json 2>&1 | Select-Object -First 5`(或任意会输出 `src/xxx.ts:行号` 的命令)
2. **预期**:输出里的 `src/main/xxx.ts:42` 这类**带斜杠**的路径,鼠标移上去出现**下划线 + 手型指针**。
3. 点击其中一个。
4. **预期**:右 dock 切到「已打开」,显示该文件;带 `:行号` 的会**滚动定位到那一行**(行居中,不做高亮)。
5. **失败现象**:路径不变蓝 / 点了没反应 / 点了不开文件 / 不跳行。

### F-2 STRICT 严格性(不该变蓝的不变)
1. 终端跑一个 node REPL 或输出含属性访问的命令,如:`node -e "console.log({a:1}.toString())"`
2. **预期**:输出里的 `.toString`、`.length` 这类**属性访问不会**变蓝(无斜杠);裸文件名 `README.md`(无斜杠)也不变蓝。
3. **失败现象**:属性访问/裸文件名也变蓝 → 误识别(说明正则太宽)。

### F-3 右键菜单「在面板打开」
1. 用鼠标**选中**终端里任意一段文本(可以是不带斜杠的裸文件名,如手动 echo 一个 `README.md`)
2. **右键** → 菜单里应有「在面板打开」项
3. 点它
4. **预期**:选中的文本被当作路径,在「已打开」面板打开(相对当前目录解析)。若文件不存在 → toast「文件不存在」。
5. **失败现象**:菜单没有该项 / 点了没反应。

### F-4 SSH session 不启用
1. 开一个 SSH session(若有配置),在其终端输出路径
2. **预期**:路径**不**变蓝;右键菜单**没有**「在面板打开」项。
3. **失败现象**:SSH 下也变蓝 / 也有菜单项。

### F-5 失败反馈
1. 点一个不存在文件的路径链接(或右键打开不存在的选中)
2. **预期**:终端底部短暂 toast「文件不存在: xxx」,不弹 modal,不打断。
3. **失败现象**:静默无反应 / 弹了 modal。

## §2 Feature E.3 · 终端状态色条动画(新,1 分钟)

### E3-1 idle → active 变宽覆盖
1. 看侧栏当前本地 session 条目(没在跑命令时)
2. **预期**:条目左侧有一条**细竖条**(info 色,rose-pine 下是青绿)
3. 在该终端跑个有持续输出的命令:`dir /s`(或 `Get-ChildItem -Recurse`)
4. **预期**:命令运行期间(session 变 active),细条**以非线性速度变宽、在约 1 秒内覆盖整个条目背景**;同时**标题文字颜色同步反色**(变深底色)。
5. **失败现象**:细条不变宽 / 文字不变色 / 动画卡顿。

### E3-2 稳态脉冲
1. 上面那个命令还在跑(active 状态持续)
2. **预期**:背景铺满后,进入**循环脉冲**(背景 opacity 缓慢呼吸,约 2.6s 一周期)。
3. **失败现象**:铺满后静止不脉冲 / 脉冲太晃眼。

### E3-3 逆动画(active → idle 收回)
1. 命令跑完(session 回 idle)
2. **预期**:背景**从满底逆收缩回细竖条**(约 1 秒),文字色同步回正。这是 idle→active 的**逆过程**(同一条曲线)。
3. **失败现象**:收回是瞬切(没动画)/ 收回动画和变宽不一致。

### E3-4 exited 灰条
1. 在某 session 里跑 `exit`(PTY 退出)
2. **预期**:条目色条变**灰细条** + 整行变暗(dim ~0.65)+ 出现退出图标(成功绿勾/失败红叉)。
3. **失败现象**:exited 没变灰 / 没有 dim。

### E3-5 reduced-motion(可选)
1. Windows 设置 → 辅助功能 → 视觉效果 → 关闭动画(或 `设置 → 辅助 → 减少动态效果`)
2. **预期**:色条动画消失,active 直接铺满静止(不脉冲、不变宽动画)。色不变。
3. 测完记得恢复设置。

## §3 Feature A · Gallery 图片表(需夹具,2 分钟)

**前置**:已 `& $m show` 打开夹具(§0 第 5 步)。滚动到「Feature A · Gallery」一节。

### A-1 幻灯片渲染 + 网络图下载
1. 看 ```gallery 代码块
2. **预期**:渲染成幻灯片——主图区 + 下方缩略图条 + 左右箭头 + 右上角指示器 `1/4`。
3. 前 3 张是网络图(picsum.photos):首次显示「加载中…(网络图)」骨架,几秒内变成图片(daemon 下载)。
4. **失败现象**:代码块没渲染成幻灯片 / 网络图一直转圈(看 main.log 有无 fetch 错误)/ 图片破图。

### A-2 切换 + 缩略图
1. 点右箭头 › / 点不同缩略图
2. **预期**:主图切换;缩略图条当前项有青绿边框高亮;指示器变 `2/4` 等。
3. **失败现象**:切换无反应 / 缩略图不高亮。

### A-3 键盘 ←/→
1. 鼠标悬停在 gallery 上(获取焦点)
2. 按键盘 ← / →
3. **预期**:切换上一张/下一张(焦点在输入框时不拦截)。

### A-4 失败态 + 重试
1. 切到第 4 张 `./gallery-local.png`(该文件不存在)
2. **预期**:主图区显示「⚠ 加载失败」+ 「重试」按钮;指示器显示 `4/4 · ⚠1`(失败计数)。
3. 点重试 → 再次尝试加载(仍失败,因为文件确实不存在)。
4. **失败现象**:失败无占位 / 无重试按钮 / 无 ⚠计数。

### A-5 点主图 → 系统查看器
1. 切到任意一张加载成功的图,点主图
2. **预期**:用系统默认图片查看器打开(网络图打开的是下载到 workspace 缓存的副本)。

### A-6 懒加载(可选)
1. 注意:只有当前 ±1 张会加载,更远的缩略图显示编号占位(不预加载)。快速连点远端缩略图,应看到骨架→图。

## §6 Feature G · 命令面板(CLI 触发,3 分钟)

**前置**:本地 session(非 SSH)。右 dock 应有「命令」tab。

### G-1 推命令 + 自动切面板
1. 终端跑:`& $m run "echo hello"`
2. **预期**:右 dock 自动切到「命令」tab,出现 1 个指令 tab,输出区显示 `hello`;终端打印 `ran: echo hello`。
3. **失败现象**:没自动切 / 没输出 / 终端报错。

### G-2 多 tab + 去重
1. `& $m run "echo world"` → 新增第 2 个 tab
2. 再 `& $m run "echo hello"`(同命令)→ **预期**:**不新增** tab(去重),该 tab 重跑一次。
3. **失败现象**:同命令新增了 tab / 没去重。

### G-3 手动重跑 + 刷新策略
1. 选中某 tab,点工具栏「↻」按钮 → **预期**:重跑该指令。
2. 刷新策略下拉选「后台 5s」,推个时间命令:`& $m run --title clock "date /t"`
3. 切到「文件」tab(让命令面板不可见)
4. 等 ~10 秒,切回「命令」tab → **预期**:clock tab 的输出时间**已更新**(后台轮询跑了)。
5. 策略改回「仅前台」,切走 → **预期**:停止轮询(切回时才跑一次)。
6. **失败现象**:后台策略切走不跑 / 前台策略切走还在跑。

### G-4 关 tab + 错误命令
1. 点某 tab 的 × → **预期**:该 tab 关闭。
2. `& $m run "not-a-real-command-xyz"` → **预期**:tab 状态显示 error,输出含退出码/⚠。
3. **失败现象**:× 关不掉 / 错误命令显示成成功。

### G-5 SSH 拒绝
1. 开 SSH session,看其右 dock → **预期**:**没有**「命令」tab。
2. **失败现象**:SSH 也有命令 tab。

## §7 Feature D · workspace 绑定/复用 + 持久化(CLI 触发,4 分钟)

**前置**:本地 session。先在「已打开」面板打开几个文件(随便 `& $m show` 几个,或通过链接打开)。

### D-1 命名 + pin
1. `& $m workspace bind --name task1`
2. **预期**:打印 `Named current workspace 'task1' (pinned)`。
3. `& $m workspace` → 打印当前 workspace 绝对路径(一个 UUID 目录)。
4. **失败现象**:报错 / 没打印。

### D-2 切到新 workspace(内容清空)
1. `& $m workspace new`
2. **预期**:打印 `Switched to a fresh empty workspace: <dir>`;**「已打开」面板变空**(新 workspace 无快照)。
3. **失败现象**:面板内容没清空(没真正切换)。

### D-3 切回命名 workspace(恢复)
1. `& $m workspace bind --name task1`(切回)
2. **预期**:打印 `Switched to existing workspace 'task1'`;**之前打开的文件 tab 恢复回来**。
3. **失败现象**:切回了但文件没恢复(快照恢复接线缺口,记下现象即可)。

### D-4 list + unpin
1. `& $m workspace list` → **预期**:列出 task1(name/files/时间/[pinned])。
2. `& $m workspace unpin --name task1` → **预期**:打印 `Unpinned`,task1 变可回收。
3. **失败现象**:list 空 / unpin 报错。

### D-5 重启恢复(可选,强测)
1. bind 一个命名 workspace + 打开文件
2. **完全退出 Marina**(关所有窗口 + 托盘退出),`npm run dev` 重启
3. 再 `& $m workspace bind --name <那个名字>` → **预期**:文件 tab 恢复。
4. **失败现象**:重启后恢复失败。

## §8 Feature E.1+E.2 · 侧栏收藏分组 + 拖拽(2 分钟)

### E12-1 分组折叠
1. 侧栏路径下有多个 session 时,看是否有分组结构(category header)
2. 点分组 header 的箭头 → **预期**:折叠/展开该组 session。

### E12-2 拖拽排序
1. 鼠标按住一个 session 条目,拖到另一个位置(同组内或跨组)
2. **预期**:出现拖拽视觉反馈(拖起占位/插入线),松手后顺序改变。
3. 拖一个 session 到分组 header 上 → **预期**:归入该组。
4. **失败现象**:拖不动 / 松手顺序没变 / 拖拽视觉卡顿。
5. **注**:刷新/重开后顺序应保持(若有持久化)。

## §9 修复项(T13 URL + 表格链接 + SCROLL-2)

### T13 · 终端 URL 可点开浏览器
1. 终端里输出一个 URL:`echo "see https://react.dev"`
2. 鼠标移到 `https://react.dev` 上 → **预期**:变蓝可点(下划线)
3. 点击 → **预期**:系统浏览器打开该 URL。
4. **失败现象**:URL 不变蓝 / 点了不开浏览器(原 bug)。

### 表格内链接换行
1. 夹具「Markdown 表格内链接换行」一节
2. **预期**:窄列里的长链接自动断行,不撑爆表格(超出靠表格横向滚动)。
3. **失败现象**:链接把表格撑得很宽 / 链接溢出单元格。

### SCROLL-2 · alt-screen TUI 滚动条不跳顶
1. 终端跑一个 alt-screen TUI:`vim`(或 `node` 进 Claude Code / Pi)
2. 在 TUI 里操作一会儿,退出
3. **预期**:退出 TUI 后,滚动条停在退出位置,**不会**跳到 scrollback 最顶部。
4. 再进 TUI、操作、退出几次,反复确认不跳顶。
5. **失败现象**:退出 TUI 后滚动条跳到最顶部(原 bug)。
