# Markdown 链接演示

这个文件是演示用的，专门展示「已打开」面板里的 Markdown 文档链接/文件链接怎么用。

下面每个链接**都可以直接点击**。会随所在目录相对解析，点击后在「已打开」面板打开对应文件。

## 1. 文档链接（指向另一个 Markdown 文件）

- [软件定义书](软件定义书.md) —— 点一下在「已打开」里打开《软件定义书.md》
- [AGENTS 工作说明](AGENTS-changelog.md) —— 打开 changelog 文档
- [README](../README.md) —— 用 `../` 跳到上级目录的文件
- [根目录的软件定义书](../docs/软件定义书.md) —— 绝对路径写法（相对本文件所在目录）

## 2. 文件链接（指向非 Markdown 文件）

- [file-panel-service.ts](../src/main/file-panel-service.ts) —— 打开一个 TypeScript 源码文件（文本查看）
- [版本号规则](版本号规则.md) —— 打开 docs 下另一份文档
- 注意：**目录**链接目前会被拒绝（提示不是文件），文件链接是 OK 的。

## 3. 外链（http / mailto）

- [打开 GitHub](https://github.com) —— 用系统浏览器打开
- [发邮件](mailto:someone@example.com) —— 走系统邮件客户端

## 怎么用

1. 在「已打开」面板里打开本文件（`docs/markdown-链接演示.md`）。
2. 点上面任意一个**本地**链接（第 1、2 节里的），观察它是否在「已打开」面板**新增了一个文件页并切过去**。
3. 配合 `ctrl/cmd + 点击` 或「在新标签打开」类动作（如果面板支持）可以并列不切换。

> ⚠️ 本演示只有本地文件链接会进「已打开」；外链（第 3 节）永远是系统浏览器打开，不会进面板——这是**设计如此**，不是 bug。
