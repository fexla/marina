# 方案：Gallery 图片表 UX 参数（ADR-026）

> 关联：[规划-v0.3.3 § Feature A](./规划-v0.3.3-AI交互丰富度-20260801.md) ·
> [Wayfinder ticket #6（T05 prototype）](https://github.com/fexla/marina/issues/6)
> 日期：2026-08-02 · 状态：已定稿（HITL 原型闭环），待实现（T09）

## 1. 背景与目标

**用户意图**：一种特殊代码块（语言标签 `gallery`），每行一个图片链接（本地路径或 URL），
渲染成幻灯片：一次一张、左右切换、不撑爆面板。点图 → 系统图片查看器开大图。

**原型**：`docs/prototypes/gallery-ux-prototype.html`（可丢弃,不进生产）——3 个结构不同的
变体（A 固定舞台 / B 自适应流式 / C 极简覆盖）模拟了主图尺寸策略、缩略图条、网络图失败态、
懒加载窗口 ±1,并模拟 8 张图(本地秒加载/网络 600ms/1 张下载失败可重试)。

**HITL 裁决**(用户,2026-08-02):
| 参数 | 裁决 | 原型对应 |
|---|---|---|
| 主图尺寸策略 | **B 自适应流式** | 主图按图片比例自适应,上限 480px |
| 缩略图条 | **A** | 固定 56px 缩略图,单行横滚 |
| 网络图失败态 | **A** | 主图区占位 + 重试按钮 + ⚠ 计数 |
| 懒加载窗口 | **±1** | 只加载当前张 ±1,窗口外骨架 |
| 其余参数 | 实现方自定,后改 | — |

## 2. 关键决策

### 2.1 主图尺寸策略：自适应流式（原型 B）
- 主图按图片自身比例渲染,`max-height: 480px` 为上限,超出按比例缩小;`max-width: 100%`。
- 每张图高度可能不同(切换时高度会跳)——接受,因为"图多大显示多大"优先于"面板稳定"。
- 主图区背景深色 `#12101d`(贴近 Rose Pine base),contain 不裁剪。
- 图下方 caption:`N / 总数 · 本地图/网络图 · 文件名`(网络图失败时不显示 caption)。

### 2.2 缩略图条：固定 56px 单行横滚（原型 A）
- 缩略图 56×56,`object-fit: cover` 裁剪,圆角 4px,当前项 2px `--rp-foam` 边框高亮。
- 单行横滚(`overflow-x: auto`),**不限制数量、不翻页**——溢出交给滚动。
- 状态:`ready` → 显示缩略图;`loading`/未加载 → 显示序号数字;`error` → ⚠ 占位,可点击跳转。

### 2.3 网络图失败态：主图区占位 + 重试 + ⚠ 计数（原型 A）
- 主图区:显示「⚠ 下载失败」+ **重试按钮**。
- 指示器右侧追加 `⚠N` 计数(已失败张数)。
- **超时:10s**;失败后**不自动重试**,只手动重试(避免对不可达 URL 反复打)。
- 重试清 error 状态重新进 loading;连续失败保持可重试,不封锁。

### 2.4 懒加载窗口:±1
- 只加载 `current ± 1`,窗口外图不发起加载,显示骨架;切近时再拉。
- 网络图尤其依赖此约束避免阻塞;本地图 dataUrl 读取同样受窗口约束。
- 切走后**未完成**的加载请求按需取消(session 内内存缓存,已加载的不重复拉)。

### 2.5 网络图下载与清理(实现方自定)
- 网络图下载到 `MARINA_WORKSPACE/__marina_gallery__/<hash>.img`,再按本地 dataUrl 处理
  (统一走 `readImageAsset` 通道,绕开 CSP `img-src` 限制;点图 openPath 对网络图也生效)。
- **清理时机:随 workspace 回收**——`__marina_gallery__` 目录跟随 workspace 生命周期,
  session 销毁/workspace 过期时一并删;运行中重复引用同一 URL 命中缓存不重复下载。
  (理由:下载缓存是 workspace 的附属产物,与文件面板快照同生命周期,不留全局孤儿。)

### 2.6 交互
- 左右箭头按钮(主图区两侧,半透明圆钮)+ 键盘 ←/→(仅 gallery 聚焦/hover 时拦截,
  避免与终端、Ctrl+F 冲突)+ 顶部指示器 `N / 总数`。
- 点击主图 → `SYSTEM_OPEN_PATH` 系统图片查看器打开**落盘后的本地文件**
  (本地图直接 openPath 原路径;网络图 openPath 下载缓存文件)。
- 缩略图点击 → 跳转到该张。

### 2.7 远程 session(SSH)
- 远程本地图路径指向远端机器文件 → `SshUnsupported` 拒绝 + 占位提示(与 file-tree/git 对称)。
- 网络图 URL 不受影响(daemon 本地可拉)。
