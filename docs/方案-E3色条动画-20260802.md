# ADR:Feature E.3 终端状态色条 ——「细条变宽覆盖」动画定稿(T06)

> 状态:已定稿(2026-08-02,T06 HITL 闭环)。
> 替代 T07 issue 原文里的「idle 黄静止 / active 绿呼吸 / exited 灰」旧设计(圆点时代遗留)。
> 原型:`docs/prototypes/e3-colorbar-prototype.html`(多主题可读性验证,可丢弃)。

## 背景

T06 要求用户提供色条参考截图以定 E.3 精确视觉。用户未提供截图,改用**文字描述**
+ 原型交互确认,最终拍板如下设计。

## 用户描述的设计意图(原话)

> 闲置的时候左侧是竖着的细条,工作起来,细条以非线性的速度变宽,覆盖整个 terminal
> 条目的背景(1s),并且 terminal 条目中的 title 字体颜色跟着细条变化的进度一起变化,
> 工作状态下,背景色(即刚刚变宽的细条)循环变化。

## 定稿决策

### 状态(两态 + 死亡态)

- **只有 idle / active 两个工作态**(用户明确:「没有所谓的退出状态,只有闲置和运行」)。
- **exited(PTY 退出)** 不归色条表达 → 复用现有 exit-code 图标 + 整行 dim 区分。
  色条在 exited 时退为灰细条(去饱和),与 idle 的彩色细条区分。

### 形态与动画

| 状态 | 色条层 | 文字色 |
|---|---|---|
| **idle** | 左侧 **3px 细竖条**(info 色) | `text-primary`(正常) |
| **active** | **width 100% 满底覆盖**(info 色)+ 稳态 opacity 脉冲 | **反色 = `bg-primary`** |
| **exited** | 左侧 3px 灰细条(`text-muted`) | `text-primary`(整行已 dim 0.65) |

- **变宽动画**:`transition: width 1s cubic-bezier(0.16, 1, 0.3, 1)`(ease-out-expo,快速冲出再缓)。
  用 `transition` 而非 `@keyframes` —— **idle↔active 正逆都平滑**(用户要求:「从运行到闲置应该做成闲置到运行的逆变化」)。
- **文字色同步**:`transition: color 1s` 同曲线,与变宽同步渐变。
- **active 稳态脉冲**:`@keyframes marina-session-bar-pulse { opacity 1↔0.6 } 2.6s`,`delay 1s`(等变宽完成再开始脉冲)。用 opacity(GPU/合成器友好,项目惯例)。
- **无障碍**:`prefers-reduced-motion: reduce` 时关闭 transition + animation,active 直接铺满静止。

### 配色:方案 A(info 满底 + 反色),`var(--color-info)` 跟主题变

- **active 背景** = `var(--color-info)`(主题主色;rose-pine=青绿、github-dark=蓝、github-light=蓝、cutie=淡紫)。
- **active 文字** = `var(--color-bg-primary)`(反色)。
- **不 color-mix 派生**(用户:「颜色硬编码就行了」)—— 直接用语义变量,简单。

### 已知取舍(用户知情接受)

scout 查证:Marina 17 套主题**无 `on-accent`/contrast 类变量**,info 满底 + 反色文字在部分主题对比度不足:

| 主题 | info 满底 + bg-primary 文字对比度 | 评价 |
|---|---|---|
| rose-pine | ~9.4 :1 | ✅ 优秀(青绿底深字) |
| github-light | ~5.0 :1 | ✅ 达标(深蓝底白字) |
| github-dark | ~5.1 :1 | ✅ 可读,但满屏高饱和蓝**审美扎眼** |
| cutie | ~2.3 :1 | ❌ 难读(淡紫底近白字) |

用户在原型里看过矩阵数值后**仍选 A + info**,接受 cutie 难读 / github-dark 满蓝。
理由:rose-pine(默认)和多数主题表现好;少数主题的瑕疵可接受,换取「满底覆盖」的强状态感知
(比通用但视觉弱的「洗涤 wash」方案更醒目)。

> 替代方案 B(洗涤 `color-mix(info 32%, transparent)` + 文字不变色)在所有主题可读,
> 但被否——覆盖感太弱,不满足用户「细条变宽覆盖整个背景」的视觉意图。

## 实现(T07)

- `src/renderer/components/Sidebar.tsx`:`<li class="session-item">` 在 `session.state==='active'`
  时追加 `active-session` class(供 CSS 反色文字)。`.session-state-bar` 的 `<span>` 结构不变。
- `src/renderer/styles/global.css`(重写 `.session-state-bar` 块):
  - `.session-item` 加 `position: relative; overflow: hidden;`;直接子元素 `z-index: 1`(浮在色条层上)。
  - `.session-state-bar` 改 `position: absolute`(背景层),`width: 3px` → `[data-state=active] width: 100%`。
  - active 文字反色 `.session-item.active-session .session-name { color: var(--color-bg-primary) }`。

## 废弃

- 旧设计「idle 黄静止 / active 绿呼吸 / exited 灰」(T07 issue 原文、决策 #16 的 3px 细条呼吸版)
  已被本 ADR 替代。旧 `@keyframes marina-session-bar-breathe`(opacity 1↔0.35)已删除,
  换为 `marina-session-bar-pulse`(opacity 1↔0.6)+ 变宽 transition。
