## Feature A · Gallery 图片表

下面这个 ```gallery 代码块会被渲染成幻灯片(主图 + 缩略图条 + 左右切换):

```gallery
https://picsum.photos/id/237/800/600
https://picsum.photos/id/1015/800/600
https://picsum.photos/id/1025/800/600
./gallery-local.png
```

**预期**:渲染出幻灯片。前 3 张是网络图(daemon 下载,首次可能短暂"加载中"),
第 4 张 `./gallery-local.png` 是本地图——若该文件不存在会显示「加载失败」占位
(正常,因为没准备这个文件)。点左右箭头/缩略图切换;点主图用系统图片查看器打开。

## Feature B · Markdown 本地文件链接

- 相对路径(上跳两层):[README](../../README.md) → 点开在「已打开」面板显示 README
- 相对路径(上跳两层):[package.json](../../package.json) → 点开显示 package.json
- 上跳两层后进子目录:[某个源码](../../src/shared/types.ts) → 点开显示 types.ts
- 不存在的文件:[不存在](./no-such-file.xyz) → 点了 toast 报「文件不存在」,面板不变
- 网页(完整 scheme):[React 文档](https://react.dev/learn) → 系统浏览器打开
- 邮件:[联系](mailto:test@example.com) → 默认邮件程序
- 页内锚点:[跳到顶部](#v033-冒烟测试夹具) → 文档内滚动
