> 状态：**Marina 侧已实现 + 测试全绿；pi package 已建。待人工集成测试。**

## 做了什么

通过 Marina 打开的 pi，每个对话自动绑定独立 workspace；切对话即切 workspace；
pi 工作完成但未查看时侧栏指示灯转警告色；对话名反映到终端名。
**pi package 是哑转发器，Marina 是决策者**（`settings.piIntegration` 控制做不做）。

## 已知限制 / 设计边界（符合 grilling 裁决）
- workspace **不命名、不 pin**，走原有 `workspaceRetentionDays` 自动回收（终端关 → release → 到期删）。跨重启 resume 时若 workspace 已回收，自动新建。
- `hasUnviewedWork` 是**通用维度**（v1 仅 pi 触发，v2 补非 pi 普遍逻辑）。
- `isPiAgent` 仅驱动 workspace 绑定，不驱动指示灯。
- active（pi 正工作）满底时不显示警告色；仅 idle 形态的 3px 竖线变色。
- 不做 workspace rename 同步、不做手动清理入口。

## 如何启用 / 安装 pi package
1. 设置页「文件面板」分类下有「pi 集成」开关（默认开）。
2. pi package 安装：`pi install /path/to/marina/packages/pi-marina-bridge`（或项目级 `-l`）。
3. 在 Marina 终端里跑 `pi` 即生效。
